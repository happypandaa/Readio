# Readio 产品需求文档（v1）

> 本文档描述"做什么、做成什么样"。界面样式以 `03-UI原型.html` 为准，技术实现以 `02-技术方案.md` 为准。三者冲突时：交互和文案以本文档为准，视觉以原型为准。

## 1. 产品概述

**一句话**：把自己找到的英文文章粘贴进来，逐句听、逐句读，遇到好句子和生词顺手收藏，收藏随时能回到原文复习。

**使用者**：中文母语的英语学习者，个人自用，在电脑浏览器里使用（手机浏览器能正常使用即可，不做专门适配）。

**核心流程**：导入文章 → 听读学习 → 收藏积累

**v1 只有两个页面**：
- **列表页**：管理文章、查看收藏
- **学习页**：以一篇文章为中心逐句听读

**v1 不做**：账号与云同步、学习进度百分比和统计、生词复习/背诵、多音色切换、手机 App、文章分类与搜索。

### 优先级说明

- **P0**：第一版必须有
- **P1**：P0 全部完成后再做

---

## 2. 名词约定

| 名词 | 含义 |
|---|---|
| 文章 | 用户粘贴的一段英文，自动切分为若干句子 |
| 句子 | 文章中的一句，有序号（从 1 开始显示，存储从 0 开始） |
| 当前句 | 学习页正在播放或即将播放的那一句，会高亮 |
| 上次位置 | 每篇文章记录的"上次学到第几句" |
| 收藏句子 | 用户收藏的一句话，附带译文和来源 |
| 收藏生词 | 用户收藏的一个单词，附带释义、原句和来源 |
| 来源 | 收藏时所在的文章标题和句子序号 |
| 句子工具条 | 学习页里鼠标移到句子上时浮出的小工具条：播放、翻译、收藏 |

## 3. 列表页

### 3.1 页面结构

自上而下：
1. **顶部栏**：左侧产品名 `Readio`；右侧主按钮「添加文章」。右侧另有一个「⋯」菜单，放「导出备份 / 导入备份」（P1）。
2. **标签栏**：左侧为标签 `文章` / `句子` / `生词`，每个标签后显示数量，如 `文章 3`。默认选中「文章」，并记住上次选中的标签（刷新后保持）。选中「句子」或「生词」时，标签栏右侧出现「展开 / 紧凑」切换（见 3.5、3.6）。
3. **内容区**：按当前标签显示对应列表。

### 3.2 「文章」标签（P0）

**排序**：按"最近学习时间"倒序；从未学习过的文章用"添加时间"参与排序。即刚添加的文章排在最前面，打开学习过的文章也会排到最前面。

**每一项显示**：
- 标题（单行，超出省略）
- 内容预览：正文前两行，超出省略
- 状态行（只显示一种，优先级从高到低）：
  - 未生成音频：`未生成音频 · 共 40 句 · 音频约 4 分钟`，后面带「生成音频」文字按钮
  - 音频生成中：`正在生成音频 12/40`，后面带「停止生成」
  - 有句子生成失败：`3 句音频生成失败`，后面带「重试」文字按钮
  - 已学完：`已学完 · 共 40 句`
  - 学习过：`上次学到第 12 句 · 共 40 句`
  - 未开始：`未开始 · 共 40 句`

**点击某一项**：打开文章详情弹窗（见 3.3）。点击状态行里的「重试」只重试音频，不打开弹窗。

**空状态**：没有任何文章时，内容区显示
- `还没有文章`
- `粘贴一段英文，就可以开始逐句听读。`
- 按钮「添加文章」

### 3.3 文章详情弹窗（P0）

电脑上居中显示，宽度约 640px；窄屏时从底部弹出、几乎铺满屏幕。弹窗分三部分，头部和底部固定，中间可滚动。

**头部**：
- 文章标题（英文字体，较大），后面跟一个「编辑」图标按钮
- 右上角「关闭」按钮
- 标题下方是状态行，和列表项的状态行完全一致（含「重试」）

**中间（可滚动）**：
1. **完整原文**：保留分段。本文已收藏的生词在原文中带收藏色的虚线下划线。原文在这里只用于阅读，单词不可点击。
2. **本文收藏的生词**：小标题 `本文收藏的生词 3`，下面按单词在文章中出现的顺序列出，每项显示：单词、音标、词性和语境释义；右侧两个图标按钮「发音」「回到原文」（进入学习页并定位到该词所在的句子，见 4.9）。
   - 没有收藏生词时显示：`还没有收藏生词。学习时点击单词，就可以查看释义并收藏。`

**底部**：
- 左侧：「删除文章」（危险色文字按钮）
- 右侧主按钮，文案按状态变化：
  - 未开始：`开始学习`
  - 学习过：`继续学习（第 12 句）`
  - 已学完：`重新学习`
- 点击主按钮：关闭弹窗，进入学习页（定位规则见 4.8）

**修改标题**：点击「编辑」后，标题原地变成输入框，后面是「保存」「取消」。标题去掉首尾空格后不能为空，最多 80 个字符；为空时「保存」不可点。按 Esc 等同于取消。

**删除**：在弹窗上方再弹出确认框
- 标题：`删除这篇文章？`
- 说明：`文章和音频会被删除，已收藏的句子和生词会保留。`
- 按钮：「删除」（危险色）「取消」
- 确认后关闭所有弹窗，列表移除该项，提示 `已删除《标题》`

**关闭弹窗**：点「关闭」、点遮罩或按 Esc（正在编辑标题时，Esc 先取消编辑）。

### 3.4 添加文章（P0）

点击「添加文章」打开弹窗（电脑上居中显示，窄屏时从底部弹出）。

**表单**：
- **标题**（选填）：单行输入框，占位文字 `不填则自动用第一句作为标题`
- **正文**（必填）：多行文本框，占位文字 `粘贴英文文章`，高度约 12 行，可滚动
- 正文下方实时显示：`约 40 句 · 音频约 4 分钟`（句数按分句规则实时计算；音频时长按 1.0 倍速每分钟约 150 词、每句另加约 0.3 秒停顿估算，不到 1 分钟显示 `不到 1 分钟`）
- 底部左侧勾选框「保存后生成音频」：**默认勾选**，记住用户上次的选择
- 按钮：「保存」「取消」

**校验**：
| 情况 | 处理 |
|---|---|
| 正文为空或只有空白 | 「保存」不可点 |
| 正文不包含任何英文字母 | 文本框下方提示 `没有识别到英文内容`，「保存」不可点 |
| 超过 300 句 | 提示 `文章太长了，最多支持 300 句，当前约 412 句`，「保存」不可点 |

**自动标题规则**：取第一句，超过 8 个单词时截取前 8 个单词并加 `…`；去掉末尾标点。

**点击保存后**：
1. 关闭弹窗，切到「文章」标签，新文章出现在列表第一位
2. 勾选了「保存后生成音频」：状态行显示 `正在生成音频 0/40`，并实时更新；没勾选：状态行显示 `未生成音频`，带「生成音频」
3. 不需要等音频生成完就可以开始学习（阅读、翻译、查词不依赖音频）

**关闭弹窗**：点「取消」、点遮罩或按 Esc。如果正文已有内容，弹窗底部的按钮区变为 `放弃这篇文章？` + 「继续编辑」「放弃」，不另外弹窗。

### 3.5 「句子」标签：收藏的句子（P0）

**排序**：收藏时间倒序。

**显示方式**：标签栏右侧「展开 / 紧凑」切换，默认「展开」。「句子」和「生词」两个标签**各自记住**自己的显示方式（刷新后保持）。

**展开模式，每一项显示**：
- 英文句子（使用正文英文字体）
- 中文翻译（较小、次要颜色）
  - 翻译还没生成好：显示 `翻译中…`
  - 翻译失败：显示 `翻译失败`，后面带「重试」
- 来源：`来自《文章标题》第 12 句`。文章已删除时显示 `来自《文章标题》（原文已删除）`
- 操作：
  - **播放**：朗读这句。正在播放时按钮变为「停止」。同一时间只播放一项。
  - **回到原文**：进入该文章学习页并定位到这一句（见 4.9）。文章已删除时按钮不可点。
  - **取消收藏**：立即从列表移除，底部提示 `已取消收藏`，带「撤销」按钮，5 秒内可撤销。

**紧凑模式**：
- 每项只显示英文句子（完整显示，可换行），右侧一个「播放」图标按钮
- 点击某一项（播放按钮以外的区域）：这一项就地切换为展开样式，操作区末尾多一个「收起」
- 切换显示方式时，所有临时展开的项恢复为该模式的默认样式

**空状态**：`还没有收藏的句子` / `在学习页把鼠标移到句子上，点星标即可收藏。`

### 3.6 「生词」标签：收藏的生词（P0）

**排序**：收藏时间倒序。

**显示方式**：同 3.5。

**展开模式，每一项显示**：
- 单词（较大、加粗），后面是音标，如 `/rɪˈzɪliəns/`
- 词性和语境释义，如 `n. 恢复力；（这里指）城市在灾后重新运转的能力`
- 原句，其中这个单词加粗显示
- 来源：同 3.5
- 操作：「发音」「回到原文」「取消收藏」，规则同 3.5

**紧凑模式**：每项只显示单词，右侧一个「发音」图标按钮；点击展开、收起的规则同 3.5。

**去重规则**：同一个单词出现在不同句子里可以分别收藏，因为语境释义不同；同一单词在同一句子里只能收藏一次。

**空状态**：`还没有收藏的生词` / `在学习页点击任意单词，即可查看释义并收藏。`

### 3.7 导出 / 导入备份（P1）

- **导出备份**：下载一个 JSON 文件，文件名 `readio-backup-2026-10-30.json`。包含文章、句子、译文缓存、收藏、上次位置和设置；**不包含音频**。
- **导入备份**：选择备份文件，确认框提示 `导入会覆盖当前所有数据，确定吗？`。备份不含音频，导入后所有文章都是「未生成音频」，需要在每篇文章里手动点「生成音频」，避免一次性批量请求语音接口。
- 文件格式不对时提示 `这个文件不是 Readio 备份`。

## 4. 学习页

### 4.1 页面结构

自上而下：
1. **顶部栏**（吸顶）：左侧「返回」，中间文章标题（单行省略），右侧显示音频状态（生成中时显示 `音频 12/40`，全部完成后不显示）。
2. **正文区**：先是大号文章标题，然后是正文，宽度适合阅读（约 680px）。
3. **播放栏**（固定在底部）：见 4.4。

### 4.2 正文展示：段落模式

- 正文按原文分段显示，**句子在段落里连续排列**，和阅读普通文章一样。每个句子是一个可识别的整体，每个单词都可以点击。
- **当前句**：像荧光笔划过一样，整句带浅色背景，底部有一条强调色细线；跨行时每一行都显示。播放时这块高亮在段落里逐句移动。
- **已收藏的句子**：句末显示一个小的实心星标（收藏色）。
- **已收藏的生词**：在正文中带收藏色的虚线下划线。

**句子工具条**：
- 电脑上，鼠标移到某句上时，这句出现浅灰背景，同时在**这句第一行开头的上方**浮出一个小工具条，包含三个图标按钮：
  - ▶ 从这句开始播放
  - 译：展开 / 收起这句的翻译（展开时按钮为选中状态）
  - ☆ 收藏 / 取消收藏这句（已收藏时为实心收藏色）
- 工具条浮在文字上方，**不挤动排版**。上方空间不够时（例如紧贴顶部栏），改为显示在这句最后一行的下方。
- 鼠标离开句子和工具条约 0.2 秒后工具条消失。鼠标从一句移到另一句时，等待约 0.15 秒再切换，方便经过其他句子移到工具条上。
- 查词卡片打开时不显示工具条。
- 触屏设备没有悬停，工具条**固定显示在当前句上**；要操作别的句子，先用上一句/下一句或刻度条把它切换为当前句。

### 4.3 听文章（P0）

**从头或从上次位置开始**：点击播放栏的播放按钮，从当前句开始播放。

**点某一句开始听**：点击该句工具条上的 ▶，从这一句开始连续播放。

**连续播放**：一句播完自动播下一句，句间停顿约 0.3 秒。当前句切换时：
- 高亮移动到新句子
- 如果新句子不在可视区域，页面自动平滑滚动，让它处于屏幕中上部

**自动滚动与手动滚动**：播放中用户手动滚动页面后，暂停自动滚动，播放栏上方出现一个小按钮「回到当前句」，点击后滚动回去并恢复自动滚动。

**播完整篇**：最后一句播完后停止，提示 `已读完这篇文章`。这篇文章标记为"已学完"，下次进入时从第 1 句开始。

**音频未就绪时**：
- 播到某句时该句音频还在生成：播放栏显示 `等待音频…`，生成完成后自动接着播放。
- 该句音频生成失败：提示 `第 12 句音频生成失败`（带「重试」），并自动跳到下一句继续播放。

### 4.4 播放栏（P0）

从左到右：
- **进度**：`12 / 40`（当前句 / 总句数）
- **上一句**：跳到上一句并播放（如原本暂停，则只移动当前句不播放）。第一句时不可点。
- **播放 / 暂停**：主按钮，尺寸最大
- **下一句**：同上一句的逻辑。最后一句时不可点。
- **语速**：显示当前语速如 `1.0×`，点击弹出选项 `0.6× 0.8× 1.0× 1.2× 1.5×`。语速对所有文章生效，并被记住。

**句子刻度条**（播放栏顶部边缘的一条细轨道）：
- 每句对应一个小格，当前句的格高亮
- 已生成音频的格为正常颜色，未生成的格为浅色，失败的格为错误色
- 点击某个格：跳到该句（播放中则从该句继续播放）
- 句子很多时格子会很细，这是允许的

**键盘快捷键**（电脑端）：
| 按键 | 作用 |
|---|---|
| 空格 | 播放 / 暂停 |
| ← / → | 上一句 / 下一句 |
| T | 展开 / 收起当前句翻译 |
| S | 收藏 / 取消收藏当前句 |
| Esc | 关闭查词卡片 |

输入框获得焦点时快捷键不生效。

### 4.5 句子翻译（P0）

- 默认只显示英文。

**「译文」开关**（学习页顶部栏右侧）：
- 打开后，所有**已经翻译过**的句子直接显示译文；没翻译过的句子不显示，也不会自动去翻译。
- 开关状态全局记住，对所有文章生效。
- 开关打开且还有句子没翻译时，正文上方显示提示条 `已翻译 12 / 40 句` + 「翻译其余 28 句」：
  - 点击后批量翻译（每次请求 10 句，同时最多 2 个请求），提示条变为 `正在翻译 20 / 40 句` + 「停止」；全部完成后提示条消失
  - 有句子失败时显示 `已翻译 37 / 40 句，3 句翻译失败` + 「重试」
  - 不用弹窗提示，用户不点也不影响阅读
- 和单句「译」的关系：开关关着时，点哪句展开哪句；开关开着时，点没翻译的句子会翻译并显示，点已显示的句子只收起这一句。切换开关时，单句的展开/收起状态清空。

- 点击某句工具条上的「译」（或按 T 展开当前句）：译文在**这句后面另起一行**显示，左侧带一条强调色竖线，段落从这里断开，下一句另起一行继续；再点收起，段落恢复原样。
- 翻译首次生成时显示 `翻译中…`；失败显示 `翻译失败`，带「重试」。
- 翻译生成后缓存，再次展开立即显示。
- 多句可以同时展开。离开学习页后展开状态不保留。

### 4.6 点击查词（P0）

**点击单词**：
- 单词获得选中样式
- 在单词附近弹出查词卡片（电脑上为浮层，窄屏为底部弹出）
- 如果正在播放，自动暂停；关闭卡片后不自动恢复

**什么算单词**：由字母组成，可包含内部的撇号和连字符，如 `don't`、`well-known`。数字和标点不可点击。

**卡片内容**：
- 单词（原文中的形式）+ 发音按钮
- 原形：当原形和原文形式不同时显示，如 `原形 run`
- 音标
- 词性 + 语境释义：这个词**在这句话里**的中文意思，一句话说清
- 按钮「收藏生词」；已收藏时显示「已收藏」（再次点击为取消收藏）

**加载与失败**：
- 加载中：卡片显示骨架占位
- 失败：`查询失败`，带「重试」

**关闭**：点卡片外部、按 Esc、或点击另一个单词（直接切换到新单词）。

同一个单词在同一句里查过后缓存，再次点击立即显示。

### 4.7 收藏句子（P0）

- 点击句子工具条上的星标（或按 S 收藏当前句）：收藏，句末出现小星标，提示 `已收藏句子`。
- 再次点击：取消收藏，提示 `已取消收藏`。
- 收藏时如果这句还没有翻译，后台自动生成翻译并保存到收藏里（用户不需要等待）。

### 4.8 记住进度（P0）

- 当前句发生变化时（播放到新句子、点击跳转、上一句/下一句），立即记录为"上次位置"。
- 进入学习页时，更新这篇文章的"最近学习时间"，列表排序随之变化。
- 再次进入时：滚动到上次位置，该句为当前句，**不自动播放**。
- 已学完的文章再次进入：从第 1 句开始，状态变回"学习过"。

### 4.9 从收藏回到原文（P0）

- 从收藏列表或文章详情弹窗的生词列表进入，都按这条规则
- 进入对应文章的学习页，滚动到对应句子
- 该句闪烁描边约 2 秒，并设为当前句
- 不自动播放
- 文章已删除时入口不可点击（见 3.5）

## 5. 音频规则

- 音频**由用户决定何时生成**：添加文章时默认勾选「保存后生成音频」；没勾选的文章、内置示例文章、从备份导入的文章都是「未生成音频」，在列表状态行、文章详情弹窗、学习页播放栏点「生成音频」开始生成。
- 学习页播放栏在未生成时显示「生成音频（约 4 分钟）」（窄屏只显示「生成音频」）；生成中显示 `生成中 12/40`。整篇音频全部生成后才能播放。
- 开始生成后，按句为整篇生成音频，**按顺序**生成（先生成前面的句子），同时最多 3 个请求。
- 单句失败自动重试 2 次，仍失败则标记为失败。用户可在列表页或学习页点「重试」，重新生成所有失败的句子。
- 生成过程中关闭或刷新页面：下次打开应用时，自动继续生成未完成的句子（只继续用户已经开始生成的文章，不会自动开始新的文章）。
- 升级前已经添加、但从来没有开始生成过的文章，升级后显示为「未生成音频」。
- 语速通过播放速度调整，不需要按语速重新生成音频。
- 单词发音在用户第一次点击发音时生成，之后缓存。
- 收藏句子的播放：优先使用文章中这句的音频；文章已删除时，第一次播放时重新生成并缓存。

## 6. 数据保留规则

| 操作 | 文章 | 句子与译文 | 句子音频 | 收藏句子 | 收藏生词 |
|---|---|---|---|---|---|
| 删除文章 | 删除 | 删除 | 删除 | **保留** | **保留** |
| 修改标题 | 更新 | — | — | 来源标题**不变**，保留收藏时的标题 | 同左 |
| 取消收藏 | — | — | — | 删除 | 删除 |

收藏时会把英文、译文、释义、原句、文章标题复制保存一份，所以文章删除后收藏仍然完整可读。

所有数据只保存在当前浏览器中。换浏览器或清除浏览器数据会导致数据丢失，这是已知限制，P1 的导出备份用于兜底。

## 7. 提示与错误文案

提示统一在页面底部居中出现，3 秒后自动消失（带「撤销」的为 5 秒）。

| 场景 | 文案 |
|---|---|
| 删除文章 | `已删除《标题》` |
| 收藏 / 取消收藏句子 | `已收藏句子` / `已取消收藏` |
| 收藏 / 取消收藏生词 | `已收藏生词` / `已取消收藏` |
| 读完整篇 | `已读完这篇文章` |
| 单句音频失败 | `第 12 句音频生成失败`（重试） |
| 网络或服务不可用 | `连接不上服务，请确认本地服务已启动` |
| 接口返回错误 | `生成失败：{服务返回的简短原因}` |

文案原则：说清楚发生了什么、可以做什么，不道歉，不用"糟糕""哎呀"之类的语气词。
