# Readio

个人英语听读应用：添加英文文章，逐句听读、翻译和查词，收藏句子、生词并恢复学习进度。学习数据保存在当前应用的本机浏览器存储中，可通过应用菜单导出 JSON 备份。

## 添加到熊猫小抽屉

在熊猫小抽屉的推荐列表选择 Readio，或在「添加应用 › 有应用链接」粘贴本仓库链接。已有下载文件夹时，选择包含 `panda.json` 的根目录添加。本应用使用 `panda.json` v2，包含 Node 24 后台，网页运行文件已随仓库提供。

## 配置和费用

首次打开前，在平台配置表单填写：

- **DeepSeek API Key**：用于翻译和查词。
- **豆包语音 API Key**：用于逐句朗读。

两项服务均由对应服务提供方按实际用量收费，额度和价格以服务提供方为准。密钥由平台保存并只交给后台，不需要发给 AI，也不需要自己创建 `.env`。

## 使用

1. 点击「添加文章」，粘贴英文正文；保存后自动分句并生成音频。
2. 打开文章开始听读；点击句子工具条翻译、播放或收藏，点击单词查词并收藏。
3. 在「句子」「生词」查看收藏；顶部菜单可导出和导入备份。

首次使用会加入两篇内置文章。音频生成失败时，先看界面原因；余额不足或密钥失效时修复平台配置，再重试。删除应用会清除应用浏览器存储，请先导出需要保留的学习数据。

## 用自己的 AI 修改

在窗口点「按你的想法改」，把需求告诉自己的 AI。AI 按平台说明修改，完成后运行 `app reload` 或请你点「重新加载」。需要排查后台时用 `app logs`；密钥仍在平台表单填写。

开发、独立运行和验证说明见 [docs/development.md](docs/development.md)。
